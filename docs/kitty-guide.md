# Kitty — The Terminal

**Your version:** kitty 0.47.1 · Fedora 44
**Config:** `~/.config/kitty/` → `~/dotfiles/kitty/.config/kitty/`

Kitty is your terminal emulator, launched by `$mod+Return`. It replaces Konsole.
Your config is deliberately tiny — four meaningful lines — so most of this guide
is about what you *can* add and how the theme mechanism works.

## 1. The files

```
~/.config/kitty/
├── kitty.conf           ← yours, hand-edited
└── current-theme.conf   ← written by `kitty +kitten themes`, do not hand-edit
```

There is also a `kitty.conf.bak` in your real config directory. It is **not**
tracked in the dotfiles repo — `.gitignore` covers `*.bak` — so it exists on
this machine only.

Config format: `key value`, one per line, `#` for comments. No quotes needed
around values, and no commas. `man kitty.conf` documents every option, and
`kitty +kitten themes` is an interactive theme picker.

## 2. `kitty.conf`, line by line

```
font_family      FiraCode Nerd Font Mono
```

The **Mono** variant matters. Nerd Fonts ship in two widths: the normal one has
double-width icon glyphs, which a terminal's fixed grid renders overlapping or
clipped. `Mono` forces every glyph to one cell. Waybar and rofi use the
non-Mono `FiraCode Nerd Font`, because they are not grid-based — that difference
is intentional, not an inconsistency.

FiraCode also has **programming ligatures**: `!=` renders as `≠`, `=>` as `⇒`.
Kitty enables them by default. To turn them off:

```
disable_ligatures always
```

```
copy_on_select yes
```

Selecting text with the mouse copies it immediately — no `Ctrl+Shift+C`. This
matches the old X11 middle-click behaviour and is the single most useful line in
the file. Paste with `Ctrl+Shift+V` or middle-click.

```
# BEGIN_KITTY_THEME
# Dimmed Monokai
include current-theme.conf
# END_KITTY_THEME
```

## 3. The theme mechanism

`include` pulls in another file, relative to `kitty.conf`'s directory. The theme
kitten uses this to keep generated colours out of your hand-written config.

**The `BEGIN_KITTY_THEME` / `END_KITTY_THEME` comments are not decoration.**
They are markers. When you run `kitty +kitten themes` and pick a theme, it:

1. writes the new colours to `current-theme.conf`, overwriting it completely, and
2. rewrites the comment *between* those two markers to the new theme's name.

So anything you put between those markers will be destroyed the next time you
change theme. Your customisations belong **outside** the block.

Your current theme is **Dimmed Monokai** — dark grey `#1e1e1e` background,
warm `#b8bcb9` foreground, a yellow `#efcc00` selection and matching active tab.

Note this is a *different* palette from waybar/rofi/swaylock, which all use
Catppuccin Mocha (`#1e1e2e` base, `#89b4fa` blue). Close enough to look
deliberate, but if you ever want them to match exactly, `kitty +kitten themes`
has a Catppuccin Mocha entry.

`current-theme.conf` also carries a `START_AUTOGENERATED_TAB_STYLE` block. Its
own comment says you may edit the colours and delete the comments — meaning
those four lines are yours to keep if you remove the markers.

### The 16 colours

`color0`–`color15` are the ANSI palette every terminal program draws from:
0–7 normal, 8–15 bright. `color1` is red, `color2` green, `color4` blue, and so
on. When `ls` or your shell prompt picks "red", it gets *your* `color1`. Changing
these changes every program's colours at once.

## 4. Applying changes

Kitty does **not** watch its config file. Three ways to apply an edit:

| Method | Scope |
|---|---|
| `Ctrl+Shift+F5` | Reload config in the running window — fastest |
| `Ctrl+Shift+F2` | Open `kitty.conf` in your editor |
| Open a new terminal | New window only; existing ones keep the old config |

Check a config file for errors without launching a window:

```bash
kitty --config ~/.config/kitty/kitty.conf --session none -e true
```

## 5. Common changes

**Font size** — not currently set, so kitty's default applies:

```
font_size 11.0
```

Live adjustment without editing anything: `Ctrl+Shift+equal` / `Ctrl+Shift+minus`,
`Ctrl+Shift+backspace` to reset. (The man page calls it `equal`, not `plus` —
you do not hold shift for the `+`.)

**Change theme** — `kitty +kitten themes`, arrow keys, Enter. It rewrites
`current-theme.conf` and the marker comment. Commit the result:

```bash
git -C ~/dotfiles diff kitty/    # see what the kitten changed
```

**Scrollback** — the default is 2000 lines:

```
scrollback_lines 10000
```

**Cursor** — `block`, `beam` or `underline`:

```
cursor_shape beam
cursor_blink_interval 0     # 0 disables blinking
```

**A little transparency** (0.0 fully transparent, 1.0 opaque):

```
background_opacity 0.95
```

**Window padding**

```
window_padding_width 6
```

**A keybinding** — kitty's own, independent of sway:

```
map ctrl+shift+enter new_window
map f1 launch --type=tab btop
```

**Stop the bell** — the audible one is off by default; this also stops the
visual flash:

```
enable_audio_bell no
visual_bell_duration 0
```

## 6. Built-in shortcuts worth knowing

None of these are configured by you — they are kitty defaults, and they work
right now.

| Keys | Action |
|---|---|
| `Ctrl+Shift+C` / `V` | Copy / paste |
| `Ctrl+Shift+F5` | Reload config |
| `Ctrl+Shift+equal` / `minus` | Font size up / down |
| `Ctrl+Shift+Up` / `Down` | Scroll a line |
| `Ctrl+Shift+H` | Open scrollback in a pager — searchable |
| `Ctrl+Shift+F` | Search scrollback |
| `Ctrl+Shift+Enter` | New kitty window (a split, inside kitty) |
| `Ctrl+Shift+T` | New tab |
| `Ctrl+Shift+E` | Open the URL under the cursor |

⚠️ Kitty has its own windows and tabs, which **overlap conceptually with sway's
tiling**. Using both gets confusing fast. Since sway already splits, tiles and
tabs windows for you, it is usually better to let sway manage layout and use
kitty as a single pane.

## 7. Troubleshooting

**Icons or powerline glyphs render as boxes.** `FiraCode Nerd Font Mono` is
missing. `fc-list | grep -c "FiraCode Nerd Font Mono"` should be non-zero. See
the bootstrap section of the repo README.

**Ligatures are unwanted** — `disable_ligatures always`.

**Colours look wrong in one program only.** That program is choosing ANSI
colours; you are seeing your `color0`–`color15`. Test the palette with:

```bash
for i in {0..15}; do printf "\e[48;5;${i}m %02d \e[0m" $i; done; echo
```

**A theme change vanished.** You edited between the `BEGIN_KITTY_THEME` and
`END_KITTY_THEME` markers, and the theme kitten overwrote it. Move the edit
outside the block.

**Config edits do nothing.** Kitty does not auto-reload. `Ctrl+Shift+F5`.

**`$mod+Return` opens nothing.** Check that `set $term kitty` in the sway config
still matches an installed binary: `command -v kitty`.
